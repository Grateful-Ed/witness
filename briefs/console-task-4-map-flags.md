# Console Task 4 — Flags on the Map

Read START-HERE.md, then the shared law in
`briefs/claude-brief-console-layout.md`, then this file.
Build ONLY this task. Depends on Task 2 (the Witness page exists to
land on). Can run parallel to Task 3.

## Scope

The one voice the map is allowed: small FLAGS for urgent items that
need a human's eyes right now.

- A flag derives only from existing data: a flagged discrepancy
  awaiting a decision, a held bin, a can't-verify item — anything
  whose record says a human is needed now. No new urgency model;
  surface what the data already says.
- A flag marks; it does not explain. Small, high-meaning, near-zero
  space: no labels, no counts, no legends on the map itself.
- Clicking a flag opens that item's Witness page.
- Nothing else earns a mark on the map. When nothing is urgent, the
  map is clean.

## Done when

- A seeded urgent item shows a flag on the map; a non-urgent item
  shows none.
- Flag click lands on the correct item's Witness page.
- Baseline suites green (668, zero fails); new tests in project
  style; frozen files untouched.
