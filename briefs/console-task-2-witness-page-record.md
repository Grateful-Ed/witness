# Console Task 2 — The Witness Page: The Record

Read START-HERE.md, then the shared law in
`briefs/claude-brief-console-layout.md`, then this file.
Build ONLY this task. Depends on Task 1 (the map).

## Scope

Clicking an item on the map — a pallet, a task, the thing in a bay —
opens that item's WITNESS PAGE with its record, two panels below a
reserved header region (the agent arrives in Task 3; leave its chair
at the top of the page, empty and labelled as coming):

- LEFT: THE EVENTS, in chronological order — the important moments
  distilled from transcripts and actions: arrived, checked, flagged,
  held, released, decided, put away. Derive ONLY from real records
  (task updates, scan verdicts, holds/releases, human posts). If the
  record has nothing, the panel is empty — never invent an event.
- RIGHT: THE FULL TRANSCRIPT — every Witness/worker interaction about
  this item, verbatim, in order. Items pass through many hands: the
  transcript accumulates multiple workers over the item's life.
  Where no transcript exists for an item, render that honestly
  (empty / "Not said"), never fabricated dialogue.

The visible trace of the human decision stays: where a human posted,
agreed, or decided, the page shows it as the human's act.

## Done when

- Map item click routes to the item's Witness page.
- Events and transcript render from existing data, multi-worker,
  in order, empty-honest.
- Baseline suites green (668, zero fails); new tests in project
  style; frozen files untouched.
